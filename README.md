# UrbanCart - eCommerce Website

UrbanCart is a fully responsive eCommerce website built using HTML, CSS, and JavaScript. The project features a modern UI design, product showcase sections, responsive layouts, and interactive components optimized for all devices.

## Features

- Fully responsive design
- Product categories and showcase
- Interactive navigation menu
- Shopping UI components
- Modern homepage banners
- Mobile-friendly layout
- Clean and user-friendly interface

## Tech Stack

- HTML5
- CSS3
- JavaScript
